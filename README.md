# СпецДорСервис — единый сайт

Статический сайт без сборки: открывайте `index.html` или выкладывайте папку целиком.

Страницы: `index.html` (главная), `dsk/`, `abz/`, `service/`, `privacy/`, `404.html`.
Пути относительные, поэтому сайт работает и из подпапки GitHub Pages (`/sds-new/`), и с корня домена.

## Что сделать до запуска

1. **Заявки.** В `script.js` в самом верху пустая строка `SDS_FORM_ENDPOINT = ""`. Пока она пустая,
   форма открывает письмо в почтовой программе посетителя (работает, но не у всех настроена почта).
   Чтобы заявки приходили сами, заведите форму в Formspree (или аналоге) и вставьте её адрес в эту строку.
2. **Картинка для ссылок в мессенджерах.** После выбора домена добавьте в `<head>` каждой страницы
   `<meta property="og:image" content="https://ВАШ-ДОМЕН/assets/img/S284_hero.jpg">`.
3. **Страница 404.** Кнопка на ней ведёт на `/`: на домене это главная, в подпапке GitHub Pages нужно заменить на `/sds-new/`.
4. **Логотип.** В шапке стоит текстовое имя «СДС». Для настоящего логотипа нужен файл с прозрачным фоном.
5. **Политика конфиденциальности** — типовой текст; покажите юристу.
6. **Шрифты** (Oswald, Golos Text) подгружаются с Google Fonts; для надёжности в РФ можно положить их в папку сайта.
