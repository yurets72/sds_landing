# СпецДорСервис — три посадочные страницы

## Файлы
- `index.html` — выбор направления
- `dsk.html` — дробильно сортировочные комплексы
- `abz.html` — асфальтобетонные заводы
- `service.html` — сервис и комплектующие
- `privacy.html` — черновая заметка о форме
- `404.html` — страница ошибки
- `assets/` — фотографии из предоставленного маркетинг кита, стили, JS и favicon

## Как проверить
Откройте `index.html` в браузере. Для корректной работы всех относительных ссылок можно загрузить папку на статический хостинг или запустить локальный сервер.

## Перед публикацией
1. Проверить телефоны, почту, часы работы и формулировки офферов.
2. Уточнить, куда должны уходить заявки. Сейчас форма открывает почтовое приложение через `mailto`; она не отправляет данные на сервер и не является CRM формой.
3. Добавить фактические политику обработки персональных данных и юридические документы, если они требуются.
4. Указать реальные домены в canonical и OG URL после выбора адресов страниц.
5. Проверить изображения и мобильный вид на реальных устройствах.
